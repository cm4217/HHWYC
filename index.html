本地服务安装向导
  1. 点「下载安装包」，浏览器会生成本地 zip 包（含 setup_ocr_server.bat / .ps1 / local_ocr_server.py）。
  2. 解压 zip，进入解压出的文件夹，双击 setup_ocr_server.bat。
  3. 脚本会自动检测 Python → 创建虚拟环境 → 安装依赖 → 启动服务（首次约 5-15 分钟，需联网下载模型）。
  4. 看到「本地 OCR 服务已启动」后，回到本页点击「检测」，再上传图片识别。
若脚本无法运行，可手动执行：python -m venv venv_ocr && venv_ocr\Scripts\activate && pip install molscribe decimer molnextr pillow rdkit && python local_ocr_server.py
常见问题：① 未安装 Python → 从 python.org 下载 3.10+ 并勾选「Add to PATH」；② 双击 .bat 闪退 → 在文件夹空白处 Shift+右键 →「在此处打开 PowerShell 窗口」→ 运行 powershell -ExecutionPolicy Bypass -File setup_ocr_server.ps1。

结构式与身份信息
怎么读这里确认"查的是哪个化合物"。名称 / CAS 登记号是化合物的官方"身份证号"，分子式给出元素组成，SMILES / InChI / InChIKey是用文本表示结构——三者指向同一个结构，若 CAS 与 SMILES 对不上，以结构为准。
化合物身份识别（多数据库搜索）
以下为各专业数据库的化合物身份 / 生物活性 / 药物信息 / 专利 / 文献检索入口，按名称或 InChIKey 跨库核对身份最可靠。
理化性质（预测 / 计算）
怎么读MW（分子量）影响投料摩尔数计算；logP（脂水分配系数）越大越亲脂，利于透膜但水溶性差；logD (pH 7.4) = 生理 pH 下的"有效"脂水分配，比 logP 更贴近真实分配行为；TPSA（极性表面积）越大极性越强、越难透过生物膜；HBD / HBA（氢键供/受体）过多不利口服吸收；可旋转键 / sp³ 比例 / 立体中心反映分子柔性、手性复杂度与代谢稳定性；pKa 决定化合物在不同 pH 下的电离与电荷状态，直接关联成盐、溶解度与跨膜——平台给出官能团经验估算值，并据此推算 logD、净电荷与等电点 pI。
可信度与模型质量评分 计算
怎么读对每个关键预测（logS / pKa / BCS / ADME）给出可信度等级（高/中/低）与依据：模型交叉印证程度、描述符完整性、分子量适用范围。写报告/做工艺决策时建议标注该等级。
种态分布（pH–物种占比） RDKit + H-H
怎么读按 Henderson-Hasselbalch 微态枚举法绘制中性/阳离子/阴离子三种物种分数随 pH 的变化，并叠加净电荷–pH 曲线。pI 处净电荷为零、中性分数最高——解释溶解度-pH 行为、成盐与等电点结晶的核心图。
盐型 / 互变异构提示 RDKit 子结构
怎么读本模块对输入结构的成盐 / 盐型与互变异构风险做提示：盐型会改变表观分子量、logP、溶解度与 pKa，工艺研发中常需区分「盐」与「游离 API」；互变异构影响 pKa、logP、溶解度与 H 键模式，是晶型/盐型筛选与杂质谱分析的关键。提示为经验粗筛，非完整枚举。
水溶解度预测（QSAR 模型）RDKit + QSAR
怎么读logS 是溶解度对数（mol/L），数值越大越易溶（0以上高溶、−2~0易溶、−4~−2可溶、−6~−4中等可溶、−6以下难溶）。mg/mL 是换算后的实用浓度（≈ g/L）。ESOL / Ali 是两种常见 QSAR 模型，结果接近则可信度高；两者有偏差属正常，可参考综合均值。API 水溶性差常是制剂难点，可结合下方 pH 表看。
热力学与几何 / 键参数 SolProp_ML + RDKit
怎么读本模块给出两类结构-性质参数：①溶剂化热力学（参考 SolProp_ML 框架，由 logS 反推溶解自由能 ΔG_solv，并估算焓 ΔH_solv、熵 ΔS_solv，以及 Abraham 溶剂化参数 E/S/A/B/L/V 与分配系数 logK / logK_aq）——用于判断分子进入水相 / 有机相的倾向；②键长 / 键能 / 键角（基于 RDKit 原子坐标与共价半径、平均 BDE 表估算），帮助快速评估骨架强度与局部几何。所有数值均为前端经验估算，非实验值。
3D 构象交互查看 RDKit / PubChem / Cactus
怎么读优先并行获取 PubChem 3D 构象记录 与 NCI/CADD Cactus 3D 的真实三维坐标；未匹配真实 3D 时，依次回退到 PubChem 2D SDF → 伪 3D 投影、RDKit 2D → 伪 3D 投影。伪 3D 基于 2D 坐标加入深度扰动生成（非力场构象），仍可拖拽旋转、滚轮缩放、切换氢原子显示，用于直观感受分子空间排布。真实分子存在多种构象异构体，此处仅为一种近似。
毒性 / 基因毒性结构警示 RDKit 子结构
怎么读本模块对结构做基因毒性（ICH M7 框架）、hERG 心脏毒性、皮肤致敏、CYP 代谢四类警示结构的子结构筛查（覆盖亚硝胺、环氧化物、烷化卤/磺酸酯、肼、重氮、芳胺/硝基等）。顶部横幅汇总检出类数与高风险数；下方按类别列出命中结构及严重度。对基因毒性杂质评估（ICH M7）与工艺安全有提示意义，但仅为结构粗筛，不能替代正式毒理/致突变研究。
谱图与固态表征（四大谱图 / 晶型·DSC·TGA）文献·专利·公开数据库
怎么读分子式 / 精确质量 / 标称质量 / 不饱和度 DBE 用来核对元素组成与环/双键数；预测分子离子 M⁺ 是 EI-MS 的母峰；同位素峰型中若 M+2 显著增高，提示含氯/溴等卤素。四大谱图（¹H/¹³C NMR、IR、MS）与原料药晶型、DSC、TGA 属实验数据，本页提供权威数据库/专利/文献查询入口，点击跳转查证。
ADME 与类药性规则（SwissADME 风格）
怎么读五套规则（Lipinski / Veber / Egan / Muegge / Ghose）从分子量、logP、TPSA、HBD/HBA、可旋转键等维度判断"是否容易做成口服药"——违例越少越"类药"。生物利用度评分估计口服吸收程度；BBB 判断能否透过血脑屏障（中枢药需要、外周药则要避免）；GI 吸收为胃肠道吸收水平；合成可及性越低越容易合成。PAINS/Brenk 警示提示可能干扰活性或毒性风险的结构片段。
类药性雷达图
怎么读六根轴分别对应 MW / logP / TPSA / HBD / HBA / 可旋转键的归一化得分（越靠近外圈=越接近理想类药区间），一眼看该化合物的"短板"在哪。
类药性进阶（先导优化 / 片段规则）计算
怎么读在 Lipinski/Veber 等「口服成药性」规则之外，本模块给出先导物优化常用规则：GSK 4/400（MW≤400 且 logP≤4）、Pfizer 3/75（logP≤3 且 TPSA≥75）、Golden Triangle（logP 0–5 且 TPSA≤140）、Rule of Three（片段 Ro3）。用于判断一个苗头/先导是否落在「易优化」的化学空间。
ESOL 溶解度贡献分解 计算
怎么读将 ESOL 综合 logS 拆为截距 / ClogP / 分子量 / 柔性四项贡献，标红最大负贡献项＝主要难溶驱动，指导「降 logP / 降 MW / 降柔性」改构方向。
ICH M7 杂质评估面板 基于毒性筛查
怎么读承接「毒性」卡片的警示结构，按 ICH M7 基因毒性杂质框架归类，给出 Ames 试验建议、TTC 限度入口与杂质谱追踪表，与「导出杂质评估表」（QS-1/API 双 Sheet）衔接。
盐型 / 晶型预测 + BCS 策略 规则
怎么读基于 pKa 给出候选盐型排序（ΔpKa 适配性：强碱适用弱酸盐，弱碱需强酸盐），并联动 BCS 分类给出制剂策略。对成盐品种（如琥珀酸盐 API）选盐直接有用。
Hansen 溶解度参数（三维） 相关性估计
怎么读给出 δD/δP/δH 三维溶解度参数与 Ro，并列出与常见溶剂的 Hansen 距离 Ra（升序＝越可能良溶），辅助结晶良/反溶剂配对与萃取体系设计。δ 值为相关性经验估计，但 Ra 排序具趋势参考价值。
温度依赖溶解度 / 重结晶相图 van't Hoff
怎么读基于 ΔH_solv 用 van't Hoff 方程外推不同温度下的固有溶解度，判断「热溶-冷却析晶」驱动力（ΔH>0 吸热溶解、升温显著增溶更适合冷却结晶；反之宜用反溶剂/蒸发析晶）。
pH–表观溶解度分布图 S₀/χ 模型
怎么读由固有溶解度 S₀ 与中性物种分数 χ_neutral 推表观溶解度 S_app(pH)=S₀/χ_neutral，绘制 pH–logS 分布曲线。中性分数越低（强电离区）表观溶解度越高——直观解释「成盐 / 调 pH 增溶」机理，与「GSE pH–溶解度曲线」同源互补。
绿色化学与工艺安全评分 分子级代理
怎么读从卤素 / 毒性警示 / 分子量 / 多环 / 高柔性等维度做分子级绿色扣分，给出总体绿色评分。注意：未纳入具体路线（原子经济性、溶剂耗量、步骤数），高分≠路线绿色。
辅料兼容性 / 制剂策略 BCS 驱动
怎么读按 BCS 分类给出辅料方向提示：BCS II（增溶剂/环糊精/固体分散体/微粉化）、III（渗透促进剂/脂质载体）、IV（组合策略）。需经兼容性实验确认。
逆合成分析提示（轻量） 子结构切断
怎么读基于检出的官能团给出候选切断键 + 对应人名反应/砌块的启发式提示（非完整路线），用于快速构思合成策略与采购清单。完整路线仍需可行性/成本/专利核查。
关键物性 / 传输性质 / 相平衡 RDKit + 外推
怎么读汇总可计算传输物性（logP/TPSA/MR/折射率/摩尔体积/氢键/柔性/芳香性）与临界性质经验外推（Tb/Tc/Pc/Vc/Tm）。临界值为经验关联、仅趋势参考，精确值需 Joback-Reid 或实验。
量子化学 / 电子结构（近似） 拓扑代理
怎么读纯前端无 QM 后端，给出偶极矩拓扑代理并诚实列出需真实 QM（DFT/半经验）方可计算的项（HOMO/LUMO、ESP 表面等），建议必要时外送 QM 服务计算回填。
有机溶剂溶解度预测（文献基线校准 + 亲脂性/极性/熔点外推） RDKit + 文献校准
怎么读基于文献《溶解度预测报告》中异噁唑啉羧酸中间体的有机溶剂溶解度基线，按亲脂性（logP，+0.30·ΔlogP）、极性（TPSA，−0.004·ΔTPSA）、熔点（−0.01·ΔMP）外推 17 种常用溶剂的溶解度（mg/mL），并给出重结晶体系建议（良溶剂＋反溶剂）与工艺/配液注意。可用于结晶、萃取、生物测试配液溶性评估。预测后将自动带入当前化合物。
GSE pH–溶解度曲线（含熔点项 · 两性/多基团 H-H 外推 · pI 最低点） RDKit + GSE
怎么读基于 GSE 方程 logS₀ = 0.5 − 0.01×(MP−25) − logP（mol/L），再用 Henderson-Hasselbalch 对酸性/碱性基团外推 pH–溶解度曲线。两性/双电离分子在 pI 处溶解度最低（净电荷为零的两性离子主导），远离 pI 因电离而升高。可与 QSAR 水溶解度（ESOL/Ali）对比。预测后将自动带入当前化合物 pKa。
缓冲容量计算（Van Slyke β 公式 · pI 处最低 · 残留酸/CO₂ 干扰） 计算
怎么读基于 Van Slyke 公式 β = 2.303·[ C·Σ Kaᵢ[H⁺]/(Kaᵢ+[H⁺])² + Kw/[H⁺] + [H⁺] ]（mol·L⁻¹·pH⁻¹），评估两性游离碱在 pI 附近的极低缓冲风险。pI 处 β 最小（两性离子主导，几乎无缓冲），极少量残留酸或溶入 CO₂ 即可显著扰动 pH。给出 pI 处 β、残留酸 ppm 阈值。默认 1% w/v，预测后自动带入当前化合物。

pH 质量标准评估（两性游离碱 pH≈pI · CO₂ 干扰 · 残留酸 ppm 换算 · 限度修订） 计算
怎么读针对两性游离碱：水溶液 pH≈pI=(pKa酸+pKa碱)/2 且与浓度基本无关；低缓冲容量下 CO₂ 与残留酸极易扰动 pH。工具给出预测 pH、限度判定、pI 处 β 与残留酸 ppm 阈值、CO₂ 干扰提示，并基于文献评估给出限度修订建议（6.5–8.0）与测定方法规定。默认 1% w/v、限度 6.0–8.0，预测后自动带入当前化合物。
针对两性游离碱（如普拉沙星 C₂₁H₂₁FN₄O₃）：水溶液 pH≈pI=(pKa酸+pKa碱)/2 且浓度基本无关；低缓冲容量下 CO₂ 与残留酸极易扰动 pH，故需明确限度与测定方法。

数据与项目管理
⑯ 化合物收藏夹（按项目分组管理）
收藏当前化合物并按项目分组（如 文拉法辛 / 艾多沙班 / PPI 类），本地持久化，刷新不丢；可导出 Excel 汇总。
⑰ 本地化合物词库自助导入（CSV / Excel）
上传 CSV / Excel（.xlsx/.xls）补充品种到本地识别词库（无需改代码）。列名支持：c(规范名)、cm(中文名，逗号分隔)、of(官方名/别名，逗号分隔)、ab(简称，逗号分隔)、cas、cas_alt(逗号分隔)、s(SMILES)、cat(类别)。导入后自动合并进识别词库并本地持久化（刷新不丢）。
⑱ 项目工作区（多品种并行管理）
按项目（如 去甲文拉法辛 / 艾多沙班 / PPI 类）组织化合物：创建项目 → 向项目添加当前化合物（含预测快照）→ 项目内点击化合物一键重查 → 项目整体导出 Excel。localStorage 持久化，刷新不丢。
